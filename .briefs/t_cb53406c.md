# Brief: Wire Real Search into Investigate Node

## Task ID
t_cb53406c

## Goal
Replace the stub document generation in `services/agent/graph/nodes/investigate.py` with real HTTP calls to `services/search/`. The agent must fetch actual documents from EU/web sources instead of creating placeholder RawDocs.

## Current State
- `services/agent/graph/nodes/investigate.py` creates a single stub `RawDoc` per iteration with hardcoded text
- `services/search/` exposes:
  - `POST /search` → `list[SearchResult]` (metadata + excerpt)
  - `POST /scrape` → `ScrapeJob` (async background task that fetches full documents)
  - `GET /jobs/{job_id}` → `ScrapeJob` (poll for completion)
- Search adapters: `ep_debates`, `eurlex`, `uk_legislation`
- No agent-side search client exists in the new architecture

## Architecture Constraints
- **HTTP-only boundaries**: agent code must NOT import from `services/search/adapters/*` directly
- All search calls go through an async HTTP client (`services/agent/tools/search_client.py`)
- Search service base URL: `SEARCH_SERVICE_URL` env var, default `http://localhost:8002`
- Agent state (`InvestigativeState`) has `plan: list[SubQuestion]` with `source_priorities: list[str]`

## Scope

### 1. Create `services/agent/tools/search_client.py`
Async HTTP client wrapping `httpx.AsyncClient`:

```python
class SearchServiceClient:
    def __init__(self, base_url: str | None = None, http_client: httpx.AsyncClient | None = None):
        ...

    async def search(self, query: str, sources: list[str] | None = None, limit: int = 10) -> list[SearchResult]:
        """Call POST /search."""

    async def scrape(self, source: str, document_ids: list[str]) -> ScrapeJob:
        """Call POST /scrape to enqueue a background fetch job."""

    async def poll_job(self, job_id: str, timeout: float = 30.0, interval: float = 1.0) -> ScrapeJob:
        """Poll GET /jobs/{job_id} until status is 'complete' or 'failed' or timeout."""

    async def fetch_documents(self, query: str, sources: list[str] | None = None, limit: int = 10) -> list[RawDoc]:
        """High-level helper: search → scrape → poll → return list[RawDoc]."""
```

Use `SearchQuery`, `SearchResult`, `Document`, `ScrapeRequest`, `ScrapeJob` models from `services/search/models.py` for request/response validation.

### 2. Update `services/agent/graph/nodes/investigate.py`

Source selection helper:
```python
def _pick_sources(plan: list[SubQuestion]) -> list[str]:
    """Flatten source_priorities from all sub-questions, deduplicate, filter to known adapters."""
    known = {"ep_debates", "eurlex", "uk_legislation", "web"}
    sources: list[str] = []
    for sq in plan:
        for src in sq.source_priorities:
            if src in known and src not in sources:
                sources.append(src)
    return sources or ["ep_debates", "eurlex"]
```
